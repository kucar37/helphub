## About the Project
**Fontys ConnectICT** is a website where ICT students can find help and collaborate with each other. I built this to solve the problem that students often don't know who to ask for help outside their own class.

## Features
* **Search for Help:** Find students with specific skills (like React or Design).
* **Rewards:** A concept for earning badges or canteen vouchers for helping others.
* **Portfolio Export:** Users can save their contributions to show in a portfolio.
